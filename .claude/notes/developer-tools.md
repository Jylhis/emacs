## admin/run-codespell -- spell checking

Runs codespell on the tracked source tree with project-specific
exclusions and dictionaries.  Requires codespell >= 2.2.2.

    ./admin/run-codespell

Config files live in `admin/codespell/`:
- `codespell.rc` -- main config
- `codespell.exclude` -- false-positive lines to skip
- `codespell.ignore` -- words to ignore
- `codespell.dictionary` -- custom dictionary

Treats many British spellings as typos and fixes them (per
`admin/notes/spelling`).

## admin/emake -- developer build wrapper

Compiles with reduced output noise and auto-runs tests on changed
files.  See build-system.md for details.

## admin/git-bisect-start -- smart bisection

Wraps `git bisect start` to automatically skip:
- Commits on merged external branches (Org, Tramp, etc.)
- Known-broken build commits

Usage:

    ./admin/git-bisect-start [git-bisect-start-args...]

Can also be wired into a git wrapper script for automatic use from
Magit (see commentary in the script).

## admin/coccinelle/ -- semantic C patches

Coccinelle (spatch) semantic patches for common C idioms:
- `nilp.cocci` -- use NILP macro
- `build_string.cocci` -- use build_string()
- `calln.cocci` -- use calln()
- `listn.cocci` -- use listn()
- `arrayelts.cocci` -- use ARRAYELTS macro
- `xzalloc.cocci` -- use xzalloc()

Run with:

    spatch --sp-file admin/coccinelle/nilp.cocci --dir src/

## admin/check-doc-strings -- docstring auditing

Perl script that finds mismatches between:
- C DEFUN parameter lists and their docstrings
- Elisp defun parameter lists and their docstrings
- Texinfo manual @defun entries and source code

Must be run from the repository root.  Dated but conceptually useful.
The script itself notes it needs modernization (2025-02-22 comment).

## CI -- EMBA (GitLab)

Continuous integration at https://emba.gnu.org/emacs/emacs.

- Triggers on branches: master, emacs-*, feature/*, fix/*
- Runs in Debian Docker containers
- Stages: build-images -> test jobs
- Job definitions: `test/infra/test-jobs.yml` (generated by
  `make -C test generate-test-jobs`)
- Build status mail: emacs-buildstatus@gnu.org
- Env var: `EMACS_EMBA_CI` set when running on EMBA

Run EMBA tests locally with Docker:

    docker buildx build --target emacs-inotify --tag emacs-inotify \
      -f test/infra/Dockerfile.emba .
    docker run --interactive --tty --env EMACS_EMBA_CI=1 \
      --name emacs-inotify emacs-inotify /bin/bash -i

Access container files via Tramp:

    C-x C-f /docker:emacs-inotify:/checkout/test/lisp/files-tests.log
