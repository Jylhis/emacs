# Security Policy

This repository is a public GitHub fork and working mirror of GNU Emacs.

Please report security issues in GNU Emacs through the upstream GNU Emacs
security process, not through public GitHub issues or pull requests in this
fork.  If a report is specific to automation, packaging, or GitHub-only
configuration in this repository, contact the repository owner privately before
publishing details.

Do not include secrets, exploit payloads, or sensitive logs in public pull
requests, Actions logs, comments, or issues.
